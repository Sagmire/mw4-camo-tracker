# MW4 Camo Tracker

A Modern Warfare 4 camo checklist (one `index.html`, vanilla JS), packaged for Windows with Electron.
Updates are published as GitHub releases in this repo and installed automatically.

## Rules from the owner

- **Never publish an update without asking first.** Wait for an explicit "publish" before pushing a
  version tag.
- Don't open or merge pull requests without asking.
- **Keep the app simple.** Prefer polishing and fixing what's there over adding features.

## Working on it

- Weapons, camos and challenge text live in the data at the top of the `<script>` in `index.html`.
- Bump the version in `package.json` for every release, and keep `README.md` current.
